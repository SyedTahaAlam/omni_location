## 0.1.0

* Initial release.
* Wi-Fi + Google Geolocation API provider.
* Cell tower + Google Geolocation API provider (Android only).
* IP geolocation provider (no permissions required).
* Bluetooth BLE beacon provider with trilateration (optional).
* Priority-based fallback chain with in-memory caching.
* Continuous location tracking via `startTracking`.
* Unified permission handling via `permission_handler`.
